# Phase 0–1 Acceptance Criteria

The milestone is complete when all items below are true.

- [ ] Python source compiles successfully.
- [ ] Unit tests pass.
- [ ] State can be loaded and atomically saved.
- [ ] Invalid state is rejected instead of silently accepted.
- [ ] Provider interface exists independently of Jules.
- [ ] Jules provider reads the API key only from environment/configuration.
- [ ] Jules provider maps authentication and quota errors to explicit exception types.
- [ ] A GitHub Actions CI workflow validates the repository on pull requests.
- [ ] A manual Jules smoke workflow can authenticate and list Jules sources.
- [ ] The smoke check confirms `M-Osugi1230/autonomous-development-engine` is visible to Jules.
- [ ] No secret value is committed to the repository.
